# DeepSeek

把 DeepSeek 网页版封装成桌面应用，用起来更方便。

## 简介

DeepSeek 是一个基于 Electron 的桌面客户端，把 DeepSeek 网页版（chat.deepseek.com）打包成了 Windows 桌面应用。打开就能用，不用再开浏览器，登录信息保存在本地，下次打开自动保持登录状态。本项目非 DeepSeek 官方项目，仅供学习交流。

## 功能

- 把 DeepSeek 网页版封装成独立桌面窗口
- 登录信息保存在本地，下次打开免登录
- 支持 Windows
- 独立窗口，不干扰浏览器
- 可打包成 exe，双击即可运行

## 使用

1. 下载对应的安装包
2. 安装并运行 DeepSeek
3. 首次打开登录 DeepSeek 账号
4. 登录信息自动保存，下次打开免登录
5. 直接对话使用，和网页版体验一致
